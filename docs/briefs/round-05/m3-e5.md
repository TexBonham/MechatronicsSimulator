# M3-E5: engine transmission efficiency switch regularised, self-locking screw held by a row (ENG-043 to 045)

Why: the N3 review (rulings 47, 48 in `docs/queue.md`) found two engine gaps behind the native adapter.
(a) `couple()` in `core/engine/src/transmission.cpp` switches the shaft gain on the sign of the power: n / eta
forward, n eta_back backward, n only at power exactly zero. A settling shaft never reaches exactly zero speed, so
every sag in [n eta, n / eta] F / K is a stable equilibrium (measured through the adapter: +3.2 % belt, +0.28 %
gear). (b) A self-locking lead screw is held only by gain 0 while the shaft velocity stays bitwise zero; that
survives only when J > n (h^2 k + h c), and a realistic rotor (1e-5 kg m^2) coasts once round-off moves it.

## Items

1. Regularised efficiency switch (ruling 47). With P = lossless * omega as today and omega_s the threshold shaft
   speed (use `MultibodyConfig::friction_slip_threshold` unless the code gives a reason for a separate field; say
   which in the report), define sigma = clamp(|omega| / omega_s, 0, 1), frozen at the step's start rate. Forward
   (P < 0): gain = n (1 + sigma (1 / eta - 1)). Backward (P > 0): gain = n (1 + sigma (eta_back - 1)). At
   omega = 0 the gain is n from both sides, continuous. Derive and state in the header comment: (i) the static
   equilibrium is unique, sag = n F / K exactly for a shaft held by a spring drive of stiffness K against an output
   force F; (ii) near rest the switch acts as a viscous torque n F (1 / eta - 1) |omega| / omega_s (forward side)
   so the approach to the static value is a creep with time constant about n F (1 / eta - 1) / (omega_s K) on that
   side and the matching expression on the backward side: publish both in the contract as the approximation the
   adapter must print; (iii) above omega_s the old gains hold exactly, so every existing moving-case assertion
   (lifting and lowering lag, gear lag) is unchanged. `PowerFlow` keeps its values; say what `Static` now means.
   Tests: belt and gear static sag through eta = 0.9 and eta_back = 0.8 equal to n F / K within the transmission
   tolerance row after the stated settling time (derive the step count from (ii), do not fit it); approached from
   above and from below; the moving cases unchanged; determinism (same run twice, identical).
2. Self-locking screw (ruling 48, ENG-044). Hold by a one-sided velocity row on the shaft in the engine's
   velocity-level pass (the pattern of the joint limit rows, ruling 43, rows appended in transmission order for
   determinism): while the coupling is in contact and the output force would back-drive the shaft (the sign of
   `lossless`), the shaft may not move in the back-driving direction, unless the shaft's own torque (applied
   generalized force plus its joint drive's spring-damper torque at the start of the step) pushes in that
   direction, in which case the row is absent and the load torque is zero as today (lowering under a drive is
   unresisted, ENG-044). The load never contributes shaft torque in the back-driving direction. Derive that the row
   does no positive work and cannot fight the drive (state the case analysis in the header). Tests, all at rotor
   inertia 1e-5 kg m^2 and again at 1e-2: holds a hanging load with no motor torque for 10 s with shaft drift
   exactly zero; holds after a lifting move stops (drive removed mid-motion); lowering under a drive proceeds;
   lifting needs torque n F / eta; a non-self-locking screw back-drives; backlash present (the row applies only in
   contact); non-convergence ends the run (ENG-025). Remove the reliance on the pivot condition and say in the
   report what the old condition was.
