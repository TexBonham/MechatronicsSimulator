## What the engine does now (E5)

The transmission gain passes linearly through n below the shaft speed omega_s = `friction_slip_threshold`
(1e-4 rad/s): forward n (1 + sigma (1 / eta - 1)), backward n (1 + sigma (eta_back - 1)),
sigma = clamp(|omega| / omega_s, 0, 1) at the start-of-step rate. The static sag of a shaft held by a spring drive
K against an output force F is exactly n F / K; the approach is a creep with time constant tau = (c + D_d) / K,
c the switch's viscous coefficient n F (1 / eta - 1) / omega_s on the forward side (eta_back on the other) and D_d
the drive's damping. A self-locking screw is held by a one-sided velocity row on the shaft; a shaft torque between
n F and n F / eta creeps the screw up at a fraction of omega_s; under a spring drive a self-locking screw's sag is
path-dependent in [0, n F / K]. `lock_torque` does not cross the bindings.
