# M3-D2: structural damping as design data (ruling 78), and the gantry's placeholders

Why: the gantry's rails and belts have no damping in the data. With zero loss a member's ringing is removed only
by the integration scheme's own decay, which depends on the step, so dynamic results do not converge as the step
is refined, and a rail released from straight or excited by a drive mode keeps ringing into the evaluation
window (G15's rails are flagged not valid for exactly that; rulings 76, 77). Zero loss is not a neutral default,
it is unphysical. Ruling 78: damping is stated in the design data as a modal damping ratio, with a low-end
literature value fixed in advance for the gantry's placeholders so it is not tuned to any result.

## Items

1. Members: a flexible member's design block takes a modal damping ratio for its first bending mode (a
   dimensionless field, default absent). The builder turns it into the lumped chain's node damping as
   stiffness-proportional damping: each node damper c = beta k with k = E I / l the node spring, and
   zeta_1 = beta omega_1 / 2, so beta = 2 zeta / omega_1, omega_1 the member's first natural frequency for its
   supports and section (unloaded: say so; a carried mass lowers the frequency and with it the realised ratio,
   state by how much in the note the builder emits). Derive in the docstring; absent means zero damping and the
   build notes say that an undamped member's ringing is set by the scheme (one line per such member, so it is
   never silent). Oracles: a cantilever and a pinned-pinned member through the native adapter, released from a
   small deflection, at a step where the scheme's own decay pi x per period is below a tenth of 2 pi zeta: the
   logarithmic decrement of the first mode is 2 pi zeta / sqrt(1 - zeta^2) within 2 percent, for zeta = 0.01 and
   0.05; the realised ratio with a carried mass against your formula.
2. Transmissions: a compliant transmission part (belt, lead screw, gear pair) takes a damping ratio of the mode
   of its driven mass on its own stiffness (catalog parameter, overridable per instance like the others, default
   absent). The builder turns it into the transmission's damping D = 2 zeta sqrt(k m) with m the driven subtree's
   mass (or inertia) the translation already uses for the mode's approximation line; absent stays zero with the
   existing line saying so. Oracle: a mass on a belt held by a fixed shaft, released from a stretch: decrement as
   above within 2 percent.
3. The gantry's placeholders (fixed here, in advance, not adjusted afterwards; each flagged as owed by the gantry
   team in the design file and in `docs/gantry-team-inputs.md` with the reason and the range): both rails
   zeta = 0.01 (a loss factor of 0.02, the low end of the range published for printed PETG and similar
   thermoplastics, about 0.02 to 0.05); the x and y belts and the lift screw zeta = 0.01 (the low end for
   fibre-reinforced timing belts and for a nut on a screw). The other shipped designs are unchanged unless they
   have a flexible member with no damping stated: list them in the report, do not change them.
4. Check on the gantry (read only otherwise): build it and print each rail's node damping, first frequency and
   time constant 1 / (zeta omega_1), and each transmission's damping and mode; the release transient of each
   rail must be below 1 percent of its static sag by the 8 s evaluation start (give the number).

5. Wiring left by the engine's rope-snap gate (INT-031, ruling 75; the engine side is merged): the adapter
   document takes `rope_snap_evaluation_start` (seconds, default 0) beside `carried_evaluation_start`; write the
   key in `mechsim/physics/native/translate.py` and set both from the case's `integrity.evaluate_from` in
   `mechsim/testing/core_driver.py` (two lines there; the carried key is already set: put the rope key beside
   it), and turn a rope's published `held_tension` (the largest tension above the breaking tension held before
   the start) into a before-evaluation line at the end of the run. One test through `CoreDriver`: a rope whose
   release transient exceeds its breaking tension before the start does not snap and gets the line; the same
   exceedance after the start snaps. For this item only you may edit those two files and the PHY and INT rows.
