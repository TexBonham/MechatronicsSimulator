# docs/briefs/

worktree layout `../MechatronicsSimulator-<id>`). Wave 1 briefs of round 3 were sent inline and are summarized in
`docs/cost-log-archive.md`; from the integration wave on, every brief is a file here first and the agent is pointed at
it. A brief carries the derivation or physics-derived bound for every number it asks a test to assert.
