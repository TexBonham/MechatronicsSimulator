Findings from the stage review, each with the coordinator's ruling:

1. Invariant 7, typed errors (mechsim/testing/core_driver.py around 626-646, runner.py around 483): `prepare_model`
   guards only StartStateError; UnmappableElementError from translate_report and the binding exception classes
   (AdapterError, KernelConfigError, SignalConfigError and the rest) from adapter.load, make_kernel, register_party
   escape `CoreDriver.run` and `_register_signals` untyped, and `run_case` does not catch around `driver.run(end)`.
   Wrap each in DriverError with the cause preserved; `run_case` turns a RunnerError or DriverError from
   `driver.run` into a run_error CaseScore with the message. One test per escape path (an unmappable design, a bad
   adapter load, a duplicate party name, a signal config error), each asserting the typed error and the score.
2. Invariant 7 and ADR 0003, approximation lines: translation report lines reach only `RecordingView.approximations`
   and the archive. Add them to RunReport and CaseScore, print them in the suite report text and the CLI output; a
   test asserts a design with a recorded approximation (finite transmission stiffness) shows the line in the score
   and the suite text.
3. Stepper, above-curve torque with a sub-half-step lead (core/signals/src/stepper.cpp around 160-166): ruling: when
   |drive torque| exceeds the available torque the motor loses synchronism whatever the lead: re-synchronize by at
   least one step in the direction of the load (sign of delta, or of the drive torque when delta is 0), count it as
   missed, stall at zero commanded speed. SIG-033 row wording follows. Test: a load above the curve at a sub-half-step
   lead loses a step every tick it persists.
4. BLD-034 versus SIG-037: ruling: the shaft body's axial inertia IS the motor's rotor inertia. The builder sets it
   (not adds); a design shaft body that declares its own axial inertia is a build error naming the body and the motor
   (BLD-034 reworded). Wire SIG-037 through mechsim/testing/core_wiring.py: `component_parameters` passes
   `shaft_axial_inertia` and `shaft_body` for every stepper so the signal layer's refusal is live; test the mismatch
   path from the Python side.
5. PHY-034 wording: the mapping has no explicit-integration limit but an envelope of its own, K_d A0 h^2 < 400
   (omega h < 20), AdapterError beyond; reword the row and the open-parameter line.
6. core_driver.py:10-11 docstring paragraph about designs without sensed joints is superseded by DES-043: delete it.
7. `RunIdentity.control_rate` records the run config's control rate, not the base rate.
8. tests/acceptance/test_acc_stubs.py around 171: read homing from the prepared case instead of a literal 15.0.
9. Python conditional expressions at core_driver.py around 683 and tests/unit/test_gantry_integration.py around 52:
