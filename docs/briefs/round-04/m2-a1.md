## 1. Sensor fidelity base (SIG-002, SIG-003, SIG-005)

Add to `BuiltinComponent` or a new `SampledSensor` base that `LimitSwitch`, `IncrementalEncoder` and A2's sensors
use, with parameters `noise` (absolute standard deviation in the sensor's output unit), `delay` (s) and
`sample_rate` (Hz), all already in the catalog:

- Noise: Gaussian N(0, noise) added to the physical quantity before quantization, drawn from the instance's child
  generator (`SignalRng` from `derive_child_seed`), one draw per sample, none when noise is 0 (no draw at all, so
  the generator stream is unchanged). Digital sensors apply noise to the position they compare against their
  threshold (a limit switch with noise chatters near its position; that is the intended physics).
- Delay: ring buffer of samples; the output at layer step n is the sample taken at the latest step m with
  (n - m) x period >= delay, so delay 0 is the current sample and delay d rounds up to `periods_ceil(d)` layer
  periods (consistent with debounce). Depth = periods_ceil(delay) + 1; a delay longer than 1e6 periods is a
  `SignalConfigError`.
- Sample rate: a sensor samples at its own rate on the layer's clock (`periods_floor(1 / sample_rate)`, at least
  1); between samples the output holds. Rate above the layer rate is a config error naming both.
- SIG-005 invariant test (C++ and the Python stub): two instances with different names and the same run seed
  produce different noise streams; the same instance under the same seed reproduces the stream exactly; a run with
  noise 0 everywhere makes no draw (assert the generator's position is unchanged).

Bounds for the noise test (derive in the test comment): N = 20000 draws of N(0, sigma): mean within
4 sigma / sqrt(N) = 0.028 sigma; sample variance within sigma^2 (1 +/- 4 sqrt(2 / (N - 1))) = +/- 4 percent.

## 2. Failure modes (SIG-006, 007, 008, 036, 034 conversions)

`FailureInjection` already carries stuck, noisy, dropped, forced_level, stall, slip. Make every sensor honour, for
`start <= n < end`: stuck = hold the last delivered output; noisy = the fault's `noise_magnitude` added on top of
the part's noise (same generator); dropped = no new sample is delivered (the consumer sees the last output held,
counters deliver no edges); forced_level = digital sensors output the level, analog sensors are a config error
naming the fault. Windows ending exactly at a tick boundary end on that tick (start inclusive, end exclusive, as

## 3. Debounce front end (SIG-010)

A level change shorter than `debounce_time` is suppressed: the output follows the input only after the input has
held a new level for `periods_ceil(debounce_time)` consecutive layer periods. Tests: a pulse of N - 1 periods is
suppressed, N periods passes, two pulses separated by less than N periods merge as the spec implies, debounce 0 is
pass-through, debounce longer than the run is a held output. Apply in `LimitSwitch` (the catalog `debounce_time`,
tier `bounce`).

## 4. Sinusoidal detent (SIG-033 edit, queue "Owed after the gate")

Physics: restoring torque tau(delta) = tau_hold sin(pi delta / (2 step_angle)) on delta = theta_cmd - theta,
maximum tau_hold at delta = step_angle, zero at 2 step_angle (pull-out, kept). The drive stays implicit and linear
(PHY-034), so publish per tick the tangent linearization: K_t = (pi tau_hold / (2 step_angle)) cos(pi delta /
(2 step_angle)) clamped below at 0.05 K_hold (K_hold = pi tau_hold / (2 step_angle), the milestone 1 value), and
rest r = theta + tau(delta) / K_t, so the linear spring's torque at the current angle equals the sinusoid's. At
delta = 0 this reduces to the milestone 1 drive exactly (K_t = K_hold, r = theta_cmd). Keep the damping term, the
torque-speed cap, the pull-out and missed-step rules and `stalled` as they are.

Reference test (derive in the test): with a static load torque T = tau_hold / 2 the equilibrium lag is
delta* = (2 step_angle / pi) asin(1 / 2) = step_angle / 3; emulate the implicit spring in the test by setting
theta_{n+1} = r_n - T / K_t,n each tick (the static solution of the linear drive); assert convergence to delta*
within 1e-6 rad inside 200 ticks and that the published torque equals T within 1e-9 relative at convergence. Add
the linearized-versus-sinusoid comparison at delta = step_angle / 2 (K_t = K_hold cos(pi / 4)). Edit the SIG-033
row text to name the tangent linearization and update `core/signals/CLAUDE.md`.
