## 1. In-process facade (FAC-001, 009, 010, 011, 012, 014, 015, 017; TST-034)

`mechsim/facade/service.py`: class `Facade(services)` built from the same `Services` the CLI builds today, with
plain synchronous methods returning pydantic result models (the `result` objects the `ok` response carries):
`list_designs(root)`, `validate(path)`, `run_case(case, design, sets, out_dir) -> RunResultSummary` (run id,
archive path, score, end reason; a driver or solver error becomes a structured `RunErrorReport` with party, time,
cause and requirement id, never an exception across the facade, FAC-014), `run_suite(...)` (scores, regression
diff, report text from brief D's `report_markdown`), `replay_open(archive) -> ReplayHandle` (archive-only, FAC-008),
`series(handle, names, t_start, t_end, points)` (decimated, FAC-007 and 018, below), `events(handle)`,
`value_at(handle, ref, t)` for body, joint, pin and signal refs (FAC-011; the `RecordView` ref forms), `report`
and `diff` for an archived suite (FAC-012), `read_file(path)` and `write_file(path, text)` validating a design or
test case against its schema before writing, refusing anything else (FAC-017). The CLI calls only `Facade`; the
runner, recorder and scoring are reachable from clients only through it (FAC-001; add the invariant test: no
module under `mechsim/cli.py` or `web/` imports `mechsim.testing`, `mechsim.record` or `mechsim.scoring`; extend
`tools/check_imports.py` RULES only if the test needs it and list the edit). FAC-015: a run through `Facade` and the
same run through the runner directly give byte-identical archives (`archives_identical`).

Decimation (FAC-007, 018): for `points` per series over `[t_start, t_end]`, min-max bucket decimation (each bucket
keeps its first sample when points >= samples; otherwise each of `points` equal buckets contributes the sample
nearest its centre), time column from the kept samples; never touches the recording (assert the archive hash
before and after).

## 2. WebSocket service (FAC-003, 005, 006, 019, 020)

`mechsim/facade/server.py`: `serve(facade, host="127.0.0.1", port=0, token) -> running server` on `websockets`
(asyncio), one connection per client, token required as `?token=` in the URL (reject the handshake otherwise),
every text frame parsed by `parse_message`; a version mismatch, unknown kind or validation failure answers `error`
with `request_id` null when unparseable (FAC-003, FAC-020, codes: `version`, `malformed`, `unknown_kind`,
`not_found`, `run_error`, `invalid_file`, `conflict`). Requests map one to one onto `Facade` methods; `run_case`
runs on a worker thread and streams `run_progress` and `tick_batch` events from `Recorder.subscribe` (FAC-006),
decimated per the client's `subscribe_series`, then `run_ended` with the reason. `tick_batch` is the header text
frame followed by exactly one binary frame of (1 + series) x samples x 8 bytes little-endian float64, time column
first (FAC-019); a header whose `byte_length` disagrees is a service bug caught by the suite. Replay requests
(`replay_open`, `scrub`, `pause`, `step`) drive the viewer's replay cursor (section 3) and answer with the cursor
state. Shutdown closes every connection with the standard close code.

Conformance suite (FAC-005): `tests/acceptance/test_facade_conformance_stubs.py` becomes the suite: a fixture
starts the server in-process on port 0 with a token, connects with the `websockets` client, and every test speaks
only protocol messages (no `Facade` call): version mismatch, bad token, each request kind on the pendulum design
and `P1_period.yaml`, streaming with `points` smaller than the sample count, byte-length check, run error report,
file write refused on an invalid design. Keep the file name; convert every stub in it. Timing: the pendulum run is
the only run; keep it to one.

## 3. Viewer module (VIE-002 to 009, 014 to 017)

`mechsim/viewer/`: everything a client shows is computed here and served through the facade. `probes.py`: body
(pose, velocity), joint (position, velocity, force), pin, signal value series from an open archive (VIE-003 to
006) by the `RecordView` refs. `timeline.py`: events from the archive's `events` table plus criterion failures from
the score, each with simulated time, category (command, fault, safety, criterion) and the label verbatim
(VIE-002). `geometry.py`: body geometry (shape kind, sizes, pose in body) read from the archived design file bytes
through the design loader (VIE-015; no file written, VIE-017). `replay.py`: `ReplayCursor` over the archive's
recorded ticks: `scrub(t)` to the nearest recorded time at or before t, `pause(bool)`, `step(forward | backward)`
one recorded sample, `advance(dt)` for a client's play loop; pure state, no clock (VIE-007 to 009, VIE-016 works
without the engine: the test runs with `mechsim._core` monkeypatched to raise on import). `__init__.py` exports
only these. Nothing in `mechsim/viewer/` imports Qt or OpenGL (invariant 9; `check_imports` allows them only here,
but this milestone needs none).
